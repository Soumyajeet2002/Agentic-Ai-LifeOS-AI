## ✨ What is Agentic AI?

Agentic AI refers to AI systems capable of moving beyond simple question-and-answer interactions.

They can combine:

**Reasoning** · **Planning** · **Memory** · **Tools** · **Knowledge** · **Execution**

to work toward a goal.



**Understand → Decide → Execute → Verify → Adapt**
